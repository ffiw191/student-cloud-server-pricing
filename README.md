## 112 元/年的 2核2G 够用吗？先看你跑什么

2核2G 能稳定跑一个 WordPress 博客、几个静态页面、课程用的 Linux 实验环境，或者低并发的小程序后端。同时开 MySQL、Redis 再挂两个站，内存就紧了，这种情况该上 2核4G。

2G 内存的余量没有想象中大：系统自己占一部分，数据库占一部分，剩下才是应用。跑一个站点刚好，再挂一个就开始吃内存。4M 带宽应付文字为主的博客没问题，图片多又没上 CDN 的站点，访客一多就会觉得慢。

流量方面，每月 300G 是轻量应用服务器的标配额度。一个普通博客一个月用几 G 到几十 G，300G 足够跑好几个小站。真正吃流量的是视频、下载文件和当图床用，这类用途要么加 CDN，要么考虑硅云那种无限流量的套餐。

超出额度后，额外购买流量的价格约为 0.8 元/G（公开资料数据，以页面为准）。偶尔超一点不心疼，长期超就该换套餐了。

## 学生云服务器价格之外，最容易忽略的三笔账

首年价格只是账单的第一行。学生优惠普遍带资格限制和限购规则，续费、流量超额和备案时间，才是后面真正影响体验的部分。

### 续费：第二年按什么价付

腾讯云校园活动的云服务器限购 1 台、三选一，学生认证资格也有期限，毕业或超出认证范围后就要按常规价格续费。官网页面留了「登录可查看旧版续费」的入口，说明不同批次购买的续费政策可能不一样，下单前在账户里确认清楚。

打算用到毕业，一次买长周期通常比年年续划算；不确定用多久，先买一年，别为了便宜囤三五年。硅云那边的资料里也给了同样的建议：预算够就直接买 2 年或 5 年，因为毕业后再也买不到学生价。

### 流量：300G 对博客够用，对视频站不够

普通博客和小项目每月几 G 到几十 G，300G 有余量。需要盯的是图片站、文件分享和视频类项目，这类用途的流量消耗是另一个量级。腾讯云轻量超出后约 0.8 元/G，硅云则是无限流量但节点在香港。选之前想清楚你的项目属于哪一类。

### 备案：卡住很多人的其实是时间

北京、上海、广州节点的服务器，用域名对外提供网站服务需要完成 ICP 备案。学生个人备案可行，但要走流程、等审核，急着上线会卡在这一步。

香港节点免备案，这是硅云 180 元/年套餐的主要卖点。如果只是用 IP 做实验、学 Linux、跑内网服务，不涉及域名，那备案就不是问题，选内地节点延迟更低。

## 按场景选：三种学生，三种买法

直接给规则，对号入座就行。

- 还没想好、只想试两周：华为云免费试用 1 个月，或者用 Azure 的 100 美元额度。

拿不准的时候，按「最低够用」原则买：先上 2核2G，确实不够再换。学生价的名额只有一次，别一上来就买超出需求的配置。
